# Centralized Design Parameters

This document records the provisional parameters, sizing rationale, and electrical boundary conditions used in the Milestone 1 CMOS differential stage.

---

## 1. Electrical Boundary Conditions

| Parameter | Symbol | Nominal Value | Unit | Tolerances / Notes |
| :--- | :--- | :--- | :--- | :--- |
| Positive Supply Voltage | $V_{DD}$ | 0.80 | V | Sub-1V low-power specification |
| Negative Supply Voltage | $V_{SS}$ / GND | 0.00 | V | Single positive supply ground reference |
| Tail Sink Current | $I_{tail}$ | 2.00 | µA | Specification target ($\pm 1\%$) |
| Branch Quiescent Current | $I_1, I_2$ | 1.00 | µA | Perfectly balanced in equilibrium |
| Reference Mirror Current | $I_{ref}$ | 2.02 | µA | Generated by on-chip resistor $R_{bias}$ |
| Input Common-Mode DC | $V_{ICM}$ | 0.60 | V | Midpoint of valid linear input window |
| Ambient Temperature | $T$ | 27.0 (300.15) | °C (K) | Standard room temperature simulation |

## 4. MOSFET Model Card Parameters (`cmos_models.inc`)

```spice
.model NMOS_LV NMOS (
+ LEVEL   = 1           ; Shichman-Hodges analytical Level 1
+ VTO     = 0.35        ; Zero-bias threshold voltage (V)
+ KP      = 150e-6      ; Intrinsic transconductance parameter (A/V^2)
+ LAMBDA  = 0.05        ; Channel-length modulation (1/V)
+ GAMMA   = 0.20        ; Body-effect parameter (V^0.5)
+ PHI     = 0.65        ; Surface inversion potential (V)
+ CGSO    = 3.0e-10     ; Gate-source overlap capacitance (F/m)
+ CGDO    = 3.0e-10     ; Gate-drain overlap capacitance (F/m)
+ CJ      = 5.0e-4      ; Zero-bias bottom junction capacitance (F/m^2)
+ CJSW    = 3.0e-10     ; Zero-bias sidewall junction capacitance (F/m)
+ TOX     = 4.0e-9      ; Gate oxide thickness (m)
)

.model PMOS_LV PMOS (
+ LEVEL   = 1           ; Shichman-Hodges analytical Level 1
+ VTO     = -0.35       ; Zero-bias threshold voltage (V)
+ KP      = 50e-6       ; Intrinsic transconductance parameter (A/V^2)
+ LAMBDA  = 0.05        ; Channel-length modulation (1/V)
+ GAMMA   = 0.20        ; Body-effect parameter (V^0.5)
+ PHI     = 0.65        ; Surface inversion potential (V)
+ CGSO    = 3.0e-10     ; Gate-source overlap capacitance (F/m)
+ CGDO    = 3.0e-10     ; Gate-drain overlap capacitance (F/m)
+ CJ      = 5.0e-4      ; Zero-bias bottom junction capacitance (F/m^2)
+ CJSW    = 3.0e-10     ; Zero-bias sidewall junction capacitance (F/m)
+ TOX     = 4.0e-9      ; Gate oxide thickness (m)
)
```

> [!WARNING]
> **Provisional Model Status:** These parameters provide an open, transparent, and reproducible baseline for analog circuit development. They are not intended to model high-order physical effects such as drain-induced barrier lowering (DIBL), velocity saturation, or subthreshold leakage. For physical fabrication, this library should be replaced with a validated foundry PDK (e.g. TSMC 180nm, SkyWater 130nm, or IHP SG13G2).
